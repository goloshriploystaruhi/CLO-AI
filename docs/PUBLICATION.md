# Состав публичной копии

Публикация создана из выбранных исходников как новый Git-репозиторий с одним исходным коммитом. Прежняя история, авторские локальные email, конфигурация старого `.git` и удалённые ранее файлы не переносятся.

Исключены личные чаты, профили, референсы, проекты CLO, резервные проекты, Figma-файлы, скриншоты, архивы, исполняемые файлы, установленные зависимости и исторические отчёты. Исходная рабочая папка и личный AppData сохранены отдельно.

Код с локальными путями приведён к переносимому выбору Python. GIF с записью рабочего экрана заменена схемой SVG, а изображение-фикстура тестов создано заново. Шрифты сохраняются по собственной лицензии, но RTF с метаданными автора редактора заменён полным обычным текстом договора.

`npm run audit:public` проверяет Git-индекс на известные форматы секретов, личные пути и запрещённые артефакты. Это дополнительная проверка, а не гарантия обнаружения любых персональных данных. Перед публикацией изменений просматривайте `git diff --cached`.

Установщик явно фиксирует HTTP-зависимость SDK `undici` на 7.30.1 через override в метаданных зависимостей и помечает изменение. Исходники OAuth не изменяются. Версия выбрана по проверке npm audit для опубликованной сборки; будущие предупреждения зависимостей требуют отдельной проверки и обновления.
