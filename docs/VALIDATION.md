# Проверка публичной версии

Проверено 30 октября 2026 года на Windows, после загрузки зафиксированного официального DevKit и установки зависимостей в отдельной папке:

- **407/407** тестов приложения — без ошибок и пропусков, с заново собранным SDK и локальной `.venv`.
- **47/47** сценариев настоящего renderer в скрытом Electron — без ошибок renderer. Подключение GPT/CLO в этих сценариях синтетическое; реальный аккаунт и рабочая сцена не использовались.
- Python: целевые наборы построения, параметрических рецептов, независимых сборок, обновления деталей и кривых проверены; тесты, ранее зависевшие от сохранённой сцены, переведены на синтетическую конструкцию. Итог: 61 уникальный тест в этих наборах, все проверены успешно с учётом повторного прогона исправленных фикстур.
- **2/2** проверки ограждения публикации: инструмент проверяет именно staged blob, даже когда рабочий файл уже изменён; секретоподобные значения и проекты отклоняются.
- Установщик создаёт `CLO AI.exe`; Python выбирается из `.venv` без привязки к окружению разработчика.
- `npm audit --omit=dev` для установленного SDK после исправления HTTP-зависимости: **0 известных уязвимостей** на момент проверки. Это не обещание отсутствия будущих уязвимостей; средства разработки upstream проверяются и обновляются отдельно.

Эти проверки не подтверждают вход с любым аккаунтом, совместимость со всеми версиями CLO, физическую посадку или готовность каждого лекала к пошиву. Настоящая геометрия в рабочий проект CLO в процессе подготовки публикации не добавлялась.
