# Ресурсы

Логотип CLO AI предоставлен автором проекта. Схемы мерок — собственные детерминированные иллюстрации. Экран подключения использует нейтральную SVG-схему без записи чьего-либо экрана.

Lebowski Regular/Bold скопированы без изменения; полный текст условий — fonts/License.txt. Исходный RTF с метаданными редактора не публикуется. Синтетическая тестовая картинка в reports/three-categories не содержит фотографий или пользовательских референсов.
