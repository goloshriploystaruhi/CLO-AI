# Участие в разработке

Опишите воспроизводимый пример, ожидаемый результат и версию CLO. Используйте синтетические мерки и простую тестовую сцену. Не прикладывайте личные данные и токены.

Изменения должны сохранять математическое построение, строгие схемы, текущую проектную память, резервное сохранение и подтверждение результата CLO. Для исправлений добавляйте регрессионный сценарий. Не объявляйте посадку проверенной по одним геометрическим тестам.

Перед отправкой: `npm test`, подходящие Python-тесты, `npm run audit:public`. Пользовательские сообщения — на русском. Условия использования самостоятельного кода пока сохраняют авторские права; предложенные изменения не означают автоматического предоставления прав на сторонние материалы.
