# Безопасность

Не публикуйте в Issues токены OAuth, файлы SDK с подключением, личные мерки, содержимое AppData или резервные проекты. Для сообщения об уязвимости используйте приватный канал GitHub Security advisories, если он доступен; в публичном обращении указывайте только общее описание без чувствительных данных.

Операции с CLO могут менять рабочую сцену. Сохраняйте проект; восстановление резервных копий и проверка посадки остаются ответственностью пользователя. Компоненты из источников и ответы AI не должны превращаться в исполняемый код.
