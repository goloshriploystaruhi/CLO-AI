# CLO AI

Экспериментальное приложение-компаньон для **CLO 3D 7.0.228 на Windows**. Позволяет обсуждать конструкцию одежды на русском языке, строить параметрические лекала, проверять геометрию и добавлять детали в открытый проект CLO.

Это самостоятельный исследовательский проект, не официальный продукт CLO Virtual Fashion или OpenAI. Публичный исходный код не означает, что любая полученная выкройка готова к раскрою и пошиву.

## Возможности

- Чат с ChatGPT через Sign in with ChatGPT, без поля для API-ключа.
- Профили мерок, пол, единицы измерения, пояснения и схематические иллюстрации.
- 23 зарегистрированные экспериментальные методики и новые декларативные конструкции: формулы, именованные точки, прямые и кривые Безье.
- Пробный расчёт, исправление обнаруженных ошибок, измерения, проверка замкнутости, самопересечений и длин сопрягаемых швов.
- Несколько независимых сборок в одном комплекте, без фиктивных соединений между ними.
- Добавление в текущий проект CLO, повторное редактирование, резервные копии и подтверждение результата от CLO.
- Память чата и параметров по проектам, исследование открытых источников и анализ прикреплённых изображений при поддержке выбранной модели.
- PDF A4/A0 в масштабе 1:1 и карта ручной сборки.

## Ограничения

Автоматическое шитьё и автоматическое размещение деталей в 3D не реализованы для этого адаптера. После замены детали ранее созданные вручную швы и размещение могут потребовать восстановления. Геометрический отчёт не подтверждает посадку, технологичность или пригодность к массовому производству: нужны проверка материала, макет и примерка.

Новая категория без готового пресета может исследоваться и строиться через математическую схему, но универсальная корректность для любой одежды не гарантируется. Неизвестные личные мерки не должны подменяться догадками; для опытного макета можно явно разрешить раскрытые допущения.

## Установка из исходников

Нужны Windows 10/11, установленный CLO 3D с Python-консолью, Git, Node.js **22.12+** с npm и Python **3.11+**. Сборка GUI-лаунчера использует компилятор .NET Framework из Windows.

```powershell
git clone https://github.com/goloshriploystaruhi/CLO-AI.git
cd CLO-AI
npm run setup
```

Установка загружает официальный DevKit на зафиксированном коммите, устанавливает его зависимости и собирает локальный SDK. Затем создаёт `.venv`, устанавливает зависимости Python и собирает `CLO AI.exe`. Эти каталоги и исполняемый файл исключены из Git. На первом запуске могут потребоваться интернет и несколько минут на загрузку Electron. Ошибка установки не означает, что вход в ChatGPT уже выполнен.

Откройте **CLO AI.exe** в папке проекта. Для рабочего стола создайте ярлык; EXE не является установщиком и должен оставаться рядом с исходниками и `vendor`. Альтернативный запуск: `npm start`.

Если Python не находится автоматически, задайте `CLO_AI_PYTHON` — полный путь к нужному `python.exe`. Привязки к Codex и личным каталогам разработчика для запуска нет.

## Первое использование

1. Войдите в ChatGPT и разрешите использование подписки, если этот способ доступен вашему аккаунту. Доступность моделей и функции определяются SDK и аккаунтом. Исходники не включают подписки CLO или ChatGPT.
2. Откройте проект в CLO. Скопируйте команду подключения в CLO AI и выполните её в Python-консоли CLO один раз за сеанс.
3. Создайте профиль мерок или явно попросите опытный макет с допущениями. Опишите изделие, размеры, материал и известные ограничения. Референсы можно прикрепить к запросу.
4. Проверьте результат в CLO. Для постоянной истории сохраняйте проект под собственным именем `.zprj`.
5. Для печати запросите PDF. Печатайте при 100% без подгонки и проверьте контрольный размер 100 мм.

Пример: «Создай трапециевидную деталь высотой 900 мм, шириной сверху 500 мм, снизу 700 мм». Затем: «Увеличь нижнюю ширину на 100 мм, сохрани верх и высоту».

## Архитектура и разработка

`app/` — Electron, UI, диалог, строгие инструменты и хранилища; корневые Python-модули и `engineering/` — геометрия, методики и проверки; `clo_bridge.py` и `clo_operations.py` — адаптер CLO; `launcher/` — Windows GUI-лаунчер; `third_party/` — лицензии и зафиксированные методические материалы. Подробности: [архитектура](docs/ARCHITECTURE.md).

```powershell
npm test
.venv\Scripts\python.exe -m unittest discover -s . -p "test_*.py"
npm run audit:public
```

Тесты приложения используют синтетические GPT/CLO и изолированные каталоги. Часть проверок требует localhost. Нативные UI-тесты запускаются отдельно в Electron; реальное взаимодействие с вашим проектом ими не подтверждается. Не запускайте диагностические native-операции в рабочей сцене без понимания их назначения.
